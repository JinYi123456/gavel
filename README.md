# GAVEL

**Every scam gets a fair trial.**

GAVEL is an agentic scam-defence courtroom. Paste a suspicious message, link, QR photo, letter or voice note
and it is booked as a case: forensic tools enter exhibits pinned to the exact words that raised them, a
prosecutor, a defence and a clerk argue from that record, and **the verdict is yours to sign on a held gavel**.
A conviction unlocks a protection order — the next-five-minutes checklist, a cooling-off clock, a redacted
alert you can hand to the people who trust you. An acquittal protects the delivery notice that really is from
the courier.

> The AI investigates. You decide. Nothing is blocked, sent, or filed for you.

## What it does

| the front | in GAVEL |
|---|---|
| Explainable detection | Exhibits quoted back onto your own message, a calibrated language reading, and the full court transcript — what each officer checked, which tool ran, and why |
| Scam prevention | Offline link and QR anatomy before anything is clicked: look-alike hosts, borrowed brand names, credential traps, program downloads |
| Security learning | Law School: twelve scam families as case law, a Daily Docket that keeps the bench sharp, and drills that turn reading into judgement |
| Safer everyday decisions | The sentencing desk: checklists, a cooling-off clock, a redacted family alert, and a case record ready for reporting |

## How the court works

```
intake (text · link · QR · document · voice — decoded on your device)
   │
   ├─ THE STATUTE BOOK     34 numbered rules — 28 charges, 6 protective marks; exact quotes
   ├─ THE ADDRESS EXAMINER link & QR-destination anatomy, fully offline
   └─ THE LANGUAGE SCORER  logistic regression, calibrated on labelled scam corpora
   │
   ▼
THE BENCH — prosecutor / defence / clerk are drafted in parallel (language-model
agents), and every draft passes THE VERIFICATION GATE before it may speak:
every word inside quotation marks must exist character-for-character in the
court record. A draft that invents evidence is discarded — the scripted bench,
compiled deterministically from the exhibits, takes the floor instead.
   │
   ▼
THE GAVEL — GUILTY · ACQUITTED · HUNG JURY. The human decides, always.
```

Three properties hold by construction, not by promise:

- **The evidence comes first, and it is deterministic.** Every tool has already run and every exhibit is on
  the record before an officer is drafted. The language models argue over a fixed record; they cannot choose
  what to inspect, so the suspect message cannot steer the investigation.
- **Fabricated evidence cannot reach the screen.** The gate checks every quote against the record; the
  scripted bench cannot invent by design.
- **A trial always finishes.** With no model service — offline, rate-limited, failing — the officers read
  the scripted record and the courtroom completes.

The message under trial is untrusted **evidence, never instructions**; attempts to steer the officers are
docketed as witness tampering.

## Measured, not promised

Every number below is regenerated by this repository's own scripts (`reports/` holds the machine-readable
versions).

| what | number | where |
|---|---|---|
| Language scorer, held-out AUC | **0.9990** | `reports/text_model_evaluation.json` |
| Language scorer, calibration error (ECE) | **0.0060** | same |
| Full engine, held-out verdicts — precision | **96.8%** | `reports/runtime_evaluation.json` |
| Full engine — scam recall · false alarms · hung | **96.0% · 0.44% · 0.87%** | same |
| Latency per case (on device) | **~0.06 ms** | same |
| Golden set — authored modern cases | **24/24** | `tests/engine.test.ts` |

The verdict band is anchored on measured operating points (low edge: ≤1% false alarms above it; high edge:
≥95% scam recall at or above it, both measured held-out). Inside the band the court returns **HUNG JURY**
instead of guessing.

## Quickstart

```bash
npm install
npm run dev        # http://localhost:3000
```

Optional, for the live officers and voice transcription — create `.env.local`:

```
FEATHERLESS_API_KEY=      # OpenAI-compatible chat completions
FEATHERLESS_BASE_URL=https://api.featherless.ai/v1
FEATHERLESS_MODEL=
FEATHERLESS_MODEL_FALLBACK=
ASSEMBLYAI_API_KEY=       # voice-note transcription
GAVEL_FORCE_SCRIPTED=     # set to 1 to run the courtroom with zero network
```

Without any keys the full courtroom works: analysis, exhibits, a scripted bench, verdict, sentencing.

## Reproduce every number

```bash
python pipeline/train_text_model.py    # trains + calibrates, exports artifacts & evaluation
node scripts/evaluate_runtime.ts      # full engine over the held-out split
npm test                               # engine suite, parity + golden cases
node scripts/eval_agents.ts           # officer drafting quality vs the verification gate
node scripts/inspect_case.ts "text"   # adjudicate any message and see everything the court saw
```

The Python trainer and the TypeScript runtime are parity-tested: the shipped TypeScript reproduces the
reference scores within 1e-6, proven by `tests/engine.test.ts` on every run.


## Privacy

- Analysis, decoders and the whole adjudication run **in your browser**. Case files live on your device.
- The only egress is opt-in by configuration: live officer drafting (message text, not stored here) and
  voice transcription (audio read, transcript returned, audio not kept here).
- Nothing is blocked, reported, contacted or filed on your behalf.

## Honest limits

- A very short message with no link and no familiar pattern can land in HUNG JURY — by design.
- Scanned image-only PDFs need selectable text; photographs of letters are not yet an intake.
- The brand register covers the majors of Malaysian banking, delivery, e-wallets and government; brands
  outside it cannot be defended by it.
- The language scorer learned from a public SMS corpus; the statute book carries the modern load, and the
  golden set — not the corpus alone — is the court's own bar exam.
